观图指引

  • 路线生长　开场金线自长安向灵山如画笔延展；底部「逐站行程」滑块共 42 档，可回溯任意一站，年份仅作刻度。
  • 检索　顶部搜索框可查地点、妖怪、神仙、回目（如「59」「第五十九回」）与难名；按 / 快速聚焦，回车直达首条结果。点「难簿」或顶部八十一难环，可逐条点开 81 难。
  • 神仙谱反查　档案卡里的神仙标签、搜索结果里的神仙条目都可点开，列出该神仙出手过的全部地点，例如「观世音菩萨」十四处、「昴日星官」两处。
  • 地点档案　悬停查看妖魔、解厄者与回目；点击展开「劫难档案卡」，含时间、妖怪、降妖神仙、原著回目、本站历难与剧情。查阅档案不会让行程倒退。
  • 团队状态　头像随收徒依次点亮；悟空在白虎岭（贬书逐走）与真假美猴王（再贬心猿）两度离队，头像转灰并标「离」，到下一站归队。
  • 援助雷达　淡紫虚线自天庭 / 南海连向需神佛出手之地；按钮在「聚焦 / 全览 / 关闭」三态间切换，聚焦模式默认只亮 3 条以内。
  • 三大地望　长卷分东土大唐（青）、西域诸国（赭）、天竺佛境（金）三色区；行至通天河结冰、女儿国飞花、火焰山起热浪、狮驼岭转暗、灵山放佛光，左侧「地望」匾额同步提示。
  • 卷轴镜头　播放时视口随笔尖缓缓横移（右上角 ◎ 可开关）；手动拖拽 / 缩放会锁定视图，点「复位」恢复跟随。窄屏默认显示当前站附近的局部长卷。
  • 劫难回放　档案卡底部「↺ 回放此劫」把本站前后三站作慢镜复演，路线回卷重绘、档案与氛围联动，结束自动回到原行程；也可点引文卷轴里的同名按钮或按 Esc 退出。
  • 原著引文　点选重点劫难时，地图上方浮出原著原句卷轴并注明回目出处；本次收录的八条引文均依百回本原文核对。
  • 快捷键　← / → 逐站移动行程，空格播放暂停，/ 搜索，Esc 收起侧栏、引文与面板并退出回放。
